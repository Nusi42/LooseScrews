# ADR 0003: Licensing

Status: accepted · 2026-10-17

## Context

Loose Screws is published on GitHub. The maintainer wants others to be able to read, run, change
and host the game, and wants changes that are given or offered to others to come back as source,
so they can be read and merged. The maintainer also wants to be able to sell a closed commercial
edition with extra changes. The game consists of code (Rust crates, the TypeScript client, the
tooling; ship models, textures and sounds are generated by that code) and of content: the
balancing, level, event and rule set data in `data/`, the media in `docs/media/`, the game design
document, and the name and logo "Loose Screws". The content was made by the maintainer with an AI
assistant; the repository contains no third-party content (no fonts, music, sound or image files
by others; the client uses system fonts).

## Decisions

- **Code: GNU Affero General Public License v3.0 or later** (`AGPL-3.0-or-later`). `LICENSE`
  holds the official text from gnu.org; the SPDX id is in the workspace `Cargo.toml` and every
  `package.json`. Anyone may build a version for themselves; whoever distributes a changed
  version, or offers it to others over a network (a game server), must make its source
  available.
- **Content: Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International**
  (`CC-BY-NC-SA-4.0`). `LICENSE-CONTENT` holds the legal code. It covers `data/`, `docs/media/`
  and `docs/design/game-design-doc.md`. Commercial use of the content needs other terms from the
  maintainer.
- **Name and logo:** "Loose Screws" and its logo are not licensed by either license; forks use
  their own name.
- **Dual licensing:** the maintainer offers the code and the content under other terms too (for
  example a closed commercial edition). Contributions come under the contributor license
  agreement in `CONTRIBUTING.md`: contributors keep their copyright and grant the maintainer a
  perpetual, irrevocable, royalty-free license to use, sublicense and relicense their
  contributions under any terms, plus a patent license; they confirm the contribution is their
  own work and give no warranty. They accept it in the pull request with a comment, or through a
  CLA tool if one is set up.
- **No copyleft dependencies:** no dependency may be under the GPL, LGPL or AGPL (code under
  someone else's GPL could never go into the closed edition). A dual license with a permissive
  option counts as permissive; MPL-2.0 build tooling of the web client is accepted (file-level
  copyleft, not linked into the game). `cargo deny check licenses` (`deny.toml`) and
  `node tools/check-licenses.mjs` enforce it in the full check and before every push.
- **No MIT parts yet:** there is no SDK or plug-in kit that third parties build on. If one is
  added, the maintainer decides whether it is MIT-licensed.
- **History:** nothing was published before this decision. The history is rewritten once so that
  every version that carries a license says the above; earlier versions carry no license grant.

## Consequences

- Nothing commercial happens before a lawyer has reviewed the contributor license agreement.
- Forks may run and change the game but cannot sell it with the original content or under the
  original name.
- New dependencies need a license check; the full check fails on a copyleft one.

## Alternatives

- **MPL-2.0 or MIT/Apache-2.0:** would let others offer a changed game server without sharing the
  source.
- **All rights reserved for content:** simplest for the commercial edition, but forks could not
  even redistribute the data the code embeds.
- **CC BY-SA 4.0 for content:** would allow commercial use of the content by anyone.
